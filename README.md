# The Auctioneer

一款使用 JavaFX 制作的拍卖行经营游戏。玩家继承了一家濒临倒闭的拍卖行，需要在 30 天内通过探索、鉴定和拍卖文物赚到 10,000,000 金币。

## 游戏玩法

- 探索旧地窖、黑市货船和亚特兰蒂斯遗迹，收集不同稀有度的文物。
- 消耗精力鉴定文物，辨别真品与赝品。
- 管理库存，并在每 7 天一次的拍卖会上选择藏品出售。
- 购买食物恢复精力，购买避水珠解锁高级区域。
- 提升拍卖行等级，在 30 天的期限内达成经营目标。

## 技术栈

- Java 21
- JavaFX 21
- FXML + CSS
- Maven

## 运行方式

请先安装 JDK 21 和 Maven，然后在项目根目录执行：

```powershell
mvn clean javafx:run
```

Maven 会自动下载 JavaFX 依赖，无需手动配置本地 JavaFX SDK。

## 项目结构

```text
src/
├─ application/   # 应用入口
├─ controller/    # 界面与游戏流程控制
├─ model/         # 玩家、文物、拍卖和全局状态模型
├─ util/          # 数据库、库存、解锁与资源工具
├─ view/          # FXML 页面
├─ image/         # 游戏图片资源
├─ music/         # 音效与背景音乐
└─ style.css      # 公共样式
```
